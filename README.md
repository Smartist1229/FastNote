# FastNote

一个使用 Tauri 2 + React + TypeScript 开发的跨平台笔记应用，内置可调用工具的 AI 笔记助手。

## 功能

- **AI 笔记助手**：内置查找、写入、按行编辑、删除、移动、回收站等笔记与分组工具，支持深度思考、工具轨迹、上下文压缩与记忆提示词；兼容 OpenAI / Claude / Gemini 三种协议，API Key 加密存储
- **本地语义搜索**：可选开启，从内置模型列表中选择并下载本地模型（推荐版约 24 MB），也可从本地目录导入自定义模型，在本机建立向量索引，按意思查找笔记（换述、同义也能命中），索引完成后完全离线；未下载模型时不影响原有文本搜索。结果是模型按相似度排序的近似匹配，受所选模型影响，未必精准
- **笔记管理**：创建、编辑、删除，实时自动保存，拖拽归类，搜索与排序
- **历史版本**：每次修改标题 / 正文 / 分组前自动快照旧版本，保留份数可配置（默认 10，1–100）；在笔记属性里可只读预览、回滚、删除单条或清空，回滚不会产生新历史
- **分组管理**：创建、编辑、删除分组，支持未分类
- **回收站**：删除进回收站可还原，超期自动清理
- **Markdown 编辑器**：代码块显示行号，笔记可导出为文件
- **外部文件**：拖入或打开电脑上的文本文件直接编辑，修改实时写回原文件，也可另存为笔记
- **导出**：分组可导出为 ZIP 压缩包或电子书（TXT / HTML / EPUB）
- **下载工具**：设置 → 工具箱可粘贴 http / https 链接下载文件，默认保存到软件安装目录的 `download` 文件夹，文件名可自定义或按链接自动获取；下载线程可调（默认 32，最高 128），语义模型下载同样使用该线程数；下载中可取消，并可一键打开下载目录
- **备份与恢复**：整库备份导入导出（JSON / SQLite 两种格式），手动备份可选是否包含 API Key 与 WebDAV 配置；支持 WebDAV 云同步，可定时自动备份到本地 / 云端，并从本地或云端备份列表中选择恢复
- **欢迎面板**：统计概览（笔记 / 分类 / 回收站）与最近更新列表
- **系统集成**：统一设置面板（可搜索）、开机自启动、托盘图标、关闭窗口行为

## 配置

### 笔记搜索

- 侧边栏搜索框内的 `.*` 图标切换正则模式：开启后按正则表达式匹配标题与正文，关闭时 `*`、`(` 等字符按字面量处理。正则不合法时本次搜索返回零结果并给出提示。

### 语义搜索

- 默认关闭。语义搜索的总开关只在「设置 → 语义搜索」里，打开后在同一分区选择模型并下载，等待索引建立。
- 可选模型（均为 int8 量化版，下载体积以面板显示为准）：
  - `BGE Small 中文`（推荐，512 维，约 24 MB）：体积小、速度快，适合大多数中文笔记。
  - `BGE Base 中文`（768 维，约 103 MB）：语义区分更细、检索更准，索引与查询更慢。
  - `Multilingual MiniLM`（384 维，约 135 MB）：支持中英等 50 多种语言，适合混写或外文笔记。
- 支持从本地导入自定义 ONNX 句向量模型：在「设置 → 语义搜索 → 导入模型」选择目录，目录内需有 `model.onnx` 与 `tokenizer.json`（单文件模型，暂不支持外部权重文件），并填写向量维度、最大 token 数、池化方式（CLS / Mean）与可选的相似度阈值。
- 导入只读取源目录，不移动或删除原文件；文件先复制到临时目录，再用填写好的元数据真实加载并嵌入一次做自检，维度不符、输出无效或文件不是有效模型都会直接报错，且不留下半成品。模型按两个文件的 SHA-256 内容哈希命名（`models/custom-<16 位哈希>/`），重复导入同一模型会提示已存在；清单记录文件大小与哈希，文件被替换后状态显示「文件缺失」，需重新导入。
- 自定义模型的维度、池化方式与阈值来自导入时填写的值，填错会在自检阶段失败；ONNX 由本地推理库解析，请只导入可信来源的模型文件。自定义模型不支持在线下载，删除后需要重新导入。
- 切换模型后，后台会按新模型重建全部笔记的向量索引；旧模型的向量不会被读取。
- 语义搜索目前为测试功能：结果是模型按相似度排序的近似匹配，不同模型的语言支持与区分能力不同，未必精准命中；功能与性能仍在调整，建议保留普通文本搜索作为主要方式。
- 「自动建立索引」默认开启：模型下载完成后自动建立索引，之后新增或修改的笔记自动增量更新。关闭后只在手动点「重建索引」时建立/更新。
- 模型目录：`<数据目录>/models/<模型 id>/`，需要 `model.onnx`、`tokenizer.json`；`manifest.json` 由下载器或首次成功加载自动生成。离线环境可手动放入前两个文件（且大小达标），再在面板里重建索引。
- 数据目录与数据库相同：优先程序所在目录下的 `data`（Windows 下如 `<安装目录>\data\models\bge-small-zh-v1.5-int8\`，整个目录可便携搬走）；安装目录不可写时退回 `%APPDATA%\com.smartist.fastnote\models\<模型 id>\`。旧版本放在应用数据目录的模型会在启动时自动迁移。面板里可复制当前模型目录，或直接在文件管理器中打开。
- 下载前会检查两个模型文件是否已完整存在，已下载的模型不会重复下载；下载源优先 `hf-mirror.com`，失败回退 `huggingface.co`；中断后支持断点续传。下载走统一的下载模块，按「设置 → 工具箱」里的线程数（默认 32，最高 128）分段并发；服务器不支持分段或文件较小时自动退回单流。同一时间只允许一个下载任务，设置面板会显示进度、已下载体积与网速；成功或失败都有提示。
- 笔记向量存放在本地 SQLite 的 `note_chunks` 表，删除模型或重建索引不会影响笔记内容。
- 开启后，AI 助手会多出 `searchNotesSemantic` 工具；检索范围仍受「AI 访问权限」约束。

### 工具箱

- **二级分类**：「下载工具」集中所有下载设置与下载表单；「指纹信息」展示随机生成的完整仿真指纹，便于确认站点可能看到的浏览器身份。
- **下载线程**：`app.config.general.downloadThreads`，默认 32，可填 1–128；改完在下一次下载任务生效，语义模型下载与工具箱下载共用。
- **链接下载**：粘贴 http / https 链接即可下载，默认保存到软件安装目录下的 `download` 文件夹（安装目录不可写时退回应用数据目录下的 `download`）。
- 请求使用浏览器指纹模块随机生成的完整浏览器特征（User-Agent、`Sec-CH-UA` 系列、Accept / Accept-Language、Fetch Metadata），并启用 Cookie 与 Referer，兼容需要这些头才允许下载的站点（例如 `https://comfy.org/download/windows/nsis/x64`）；同一任务的所有分段请求共用一个指纹，不同任务之间重新随机。默认头不带 `Accept-Encoding`，保证 Range 分段与 `Content-Length` 一致。
- 文件名可自定义；留空时优先读取响应头 `Content-Disposition`（含 RFC 5987 的 `filename*` 中文名），没有时再取链接路径的最后一段。两种方式都会做非法字符清理；重名时自动追加 ` (1)`、` (2)`，不覆盖已有文件。下载过程显示进度、体积、网速与实际分段数（服务器不支持 Range 时提示已退回单线程），可随时取消，取消后清理临时文件；完成后提示保存路径并可在文件管理器中定位，也可直接打开下载目录。
- 分片与下载计划放在下载目录下以下载文件名命名的临时文件夹（如 `FastNote_2.5.6.exe` 对应 `download/FastNote_2.5.6`，无扩展名时追加 `-parts`），下载完成后合并成最终文件放回 `download` 根目录，并删除临时文件夹；失败或取消时同样清理临时文件夹，只留下已完成的下载文件。

### 浏览器指纹

- 设置 → 工具箱 →「指纹信息」可直接查看一份完整指纹（基础信息、Navigator、UA-CH / Client Hints、屏幕与窗口、WebGL、WebGPU、音频与媒体设备、网络 / 存储 / 电池、字体、插件、语音合成、API 能力），点「换一个」可重新随机生成。
- 后端的 `fingerprint` 模块每次调用 `BrowserFingerprint::random()` 都会生成一份新的随机指纹，并通过 `headers()` 得到与之匹配的导航请求头；需要固定身份时，调用方应保存这一份实例并在后续请求中复用。
- 指纹字段：`user_agent`、`chrome_major` / `chrome_version`、`brands` / `full_version_list`（UA-CH）、`platform` / `ua_platform` / `ua_platform_version` / `ua_architecture` / `ua_bitness` / `ua_mobile` / `ua_model` / `ua_wow64` / `ua_form_factors`、`language` / `languages`、`timezone`、`hardware_concurrency`、`device_memory_gb`、`color_scheme`、`reduced_motion`、`do_not_track`、`navigator`（appCodeName / appName / appVersion / product / vendor / webdriver / cookieEnabled / onLine / pdfViewerEnabled / maxTouchPoints / GPC）、`screen`、`window`（内外尺寸、位置、DPR）、`webgl`（掩码与未掩码供应商/渲染器、版本、上下文属性、上限、扩展）、`webgpu`（适配器、特性、limits）、`audio`（采样率、声道、延迟、压缩器）、`media`（输入输出数量与 64 位设备 ID）、`network`、`storage`、`battery`、`canvas_seed` / `audio_seed`、`fonts`、`plugins`、`mime_types`、`voices`、`api_features`。
- 随机生成时按平台（Windows / macOS / Linux）成套取值：UA、UA-CH、屏幕、窗口、WebGL / WebGPU、字体与语音互相匹配，本机平台出现概率更高；语言、时区、Chrome 版本、GPU、硬件、媒体设备、网络、存储、Canvas / Audio 种子等独立随机，避免出现 Windows UA 配 `MacIntel`、ARM 配 Intel 核显之类的自相矛盾组合。下载模块在创建客户端时取一次，同一任务内保持一致。
- 边界：本模块生成的是浏览器可观测属性和对应的 HTTP 请求头，不运行网页 JS，也不改变 TLS / HTTP2 握手特征。对只检查 UA、Client Hints、Cookie 等请求头的站点足够用；对有 TLS 指纹或页面内 JS 检测的站点，无法保证 100% 隐身，实际兼容性取决于目标站的检测维度。

### 笔记历史

- **保留份数**：`app.config.general.noteHistoryLimit`，默认 10，可填 1–100。每次标题、正文或所属分组变化前，先把修改前的版本写入 `notes_history`；超出份数后删除最早的版本。
- **回滚入口**：右键笔记 →「笔记属性」→「历史版本」，列出标题、保存时间与字数。点「预览」会在编辑器中只读展示该版本，顶部提示条可「回滚到此版本」或「退出预览」，预览期间不能编辑、也不会保存。
- **回滚**：确认后恢复该版本的标题、正文、分组与置顶状态。回滚只做覆盖写入，**不会**先把当前版本存成新历史，反复回滚不会让历史列表变长；回滚前尚未落盘的输入会被丢弃（不会写回笔记，也不产生历史），需要保留当前内容时先预览或手动复制。
- **删除与清空**：历史条目可逐条删除，也可一次清空当前笔记的全部历史，两种操作都需要二次确认。
- 历史版本随笔记永久删除而清理，也包含在整库备份中。

### 备份与恢复

- **备份内容**：笔记（含回收站、置顶与逐条 AI 访问权限）、历史版本（`notes_history`）、分组、标签及其关联、AI 服务商配置、AI 会话与消息、以及 `app_settings` 整表（通用 / 编辑器 / 布局 / 视图 / 主题与自定义主题、AI 设置与提示词记忆、最近文件与搜索历史、下载线程数、笔记历史份数、语义搜索开关与所选模型等）。恢复是覆盖式：先清空这些表，再按备份里的 id 原样写回。
- **手动备份可选内容**：导出时可勾选「备份 API Key」与「备份 WebDAV 配置」，两者默认都不勾选；自动备份（本地与云端）永远不包含这两项。
- **WebDAV 配置**：未勾选时整组 `webdav.*` 设置都不写入备份；勾选后写入服务器、账号、密码与自动备份配置，但始终排除仅对本机有意义的运行状态（`webdav.lastAutoBackupAt` / `lastAutoAttemptAt` / `lastAutoError` / `lastAutoFile`）。恢复时按「备份里有就用备份、没有就保留本机」合并，避免一次恢复把本机正在用的云端配置抹成默认值。
- **不含的内容**：语义向量索引与 `<数据目录>/models` 下的模型文件（包括自定义导入的模型）。恢复后需重新下载或重新导入模型，向量由后台重建；恢复同时会清空语义元数据，因此不会残留恢复前的索引维度与失败提示。工具箱的 `download` 目录、被编辑的外部文本文件本身也不在备份范围内。
- **JSON 格式**：带字段级兼容逻辑，旧版本备份同样能恢复，适合换机迁移。勾选「备份 API Key」时 Key 以明文写入文件；勾选「备份 WebDAV 配置」时密码同样以明文写入，请妥善保管。恢复导入时会重新加密密码。
- **SQLite 格式**：`VACUUM INTO` 生成的独立整库快照（`.db`），恢复更快，适合本机定期备份；快照内含 `fastnote_backup_meta` 标记表，非本软件导出的数据库会被拒绝导入。Key 与 WebDAV 密码保持本机加密值，主密钥 `<数据目录>/fastnote.key` 不随备份走，换机后解不开，恢复时会尝试沿用本机同名服务商的 Key。

### WebDAV 云同步

- **连接配置**（设置 → 备份与恢复）：服务器地址（WebDAV 根地址）、账号、密码、云端文件夹。文件夹默认 `FastNote`，不存在时通过 MKCOL 自动创建；支持 Basic Auth 的 Nextcloud、群晖、坚果云、Alist 等常见服务。
- **配置项**：`app.config.webdav.server` / `username` / `folder` / `autoBackup` / `autoIntervalHours`（1–720，默认 1）/ `autoTarget`（`local` 仅本地、`cloud` 仅云端、`both` 云端 + 本地，默认 `both`）/ `autoMaxLocal`（1–200，默认 10）。密码不在这组配置里，由后端加密后单独存 `webdav.password`。
- **自动备份**：后台按间隔生成 JSON 备份，只含数据与设置、**永不含 API Key 与 WebDAV 配置**。失败后 10 分钟重试；界面显示最近一次成功时间、文件名与错误。
- **本地备份目录**：软件安装目录下的 `backup`（不可写时退回应用数据目录下的 `backup`）。自动备份文件名形如 `fastnote-auto-YYYYMMDD-HHMMSS.json`，按「本地最多保留」删除最早的自动备份；云端备份不自动清理。
- **手动备份到云端**：立即上传一份 `fastnote-YYYYMMDD-HHMMSS.json`，是否包含 API Key 与 WebDAV 配置由「备份与恢复」里的两个开关决定。
- **恢复**：支持从本地备份目录或云端备份列表选择文件；云端列表通过 PROPFIND 获取（按修改时间倒序），选择后下载到临时文件再覆盖恢复，临时文件用完即删。恢复前会先写入主题的待保存改动，恢复成功后界面自动刷新。

## 构建

```bash
pnpm install          # 安装依赖
pnpm dev              # 开发模式（桌面端）
pnpm build            # 打包桌面应用
```

首次构建 Rust 端时，`ort` 会从 `cdn.pyke.io` 下载 ONNX Runtime 预编译库并缓存；离线构建需提前准备缓存。语义模型不随安装包分发，运行时按需下载。

## 技术栈

- 前端：React 19 + TypeScript + Vite + Tailwind CSS
- 桌面端：Tauri 2 (Rust 后端)
- 编辑器：自研 Markdown 编辑器（src/markdown-editor，自研解析器 + 三种视图 + 全量可配置）
- 数据库：SQLite（笔记数据 + AI 设置加密存储）
