# FastNote

一个使用 Tauri 2 + React + TypeScript 开发的跨平台笔记应用，内置可调用工具的 AI 笔记助手。

## 功能

- **AI 笔记助手**：内置查找、写入、按行编辑、删除、移动、回收站等笔记与分组工具，支持深度思考、工具轨迹、上下文压缩与记忆提示词；兼容 OpenAI / Claude / Gemini 三种协议，API Key 加密存储
- **本地语义搜索**：可选开启，从内置模型列表中选择并下载本地模型（推荐版约 24 MB），也可从本地目录导入自定义模型，在本机建立向量索引，按意思查找笔记（换述、同义也能命中），索引完成后完全离线；未下载模型时不影响原有文本搜索。结果是模型按相似度排序的近似匹配，受所选模型影响，未必精准
- **笔记管理**：创建、编辑、删除，实时自动保存，拖拽归类，搜索与排序
- **分组管理**：创建、编辑、删除分组，支持未分类
- **回收站**：删除进回收站可还原，超期自动清理
- **Markdown 编辑器**：代码块显示行号，笔记可导出为文件
- **外部文件**：拖入或打开电脑上的文本文件直接编辑，修改实时写回原文件，也可另存为笔记
- **导出**：分组可导出为 ZIP 压缩包或电子书（TXT / HTML / EPUB）
- **下载工具**：设置 → 工具箱可粘贴 http / https 链接下载文件，默认保存到软件安装目录的 `download` 文件夹，文件名自动获取；下载线程可调（默认 32，最高 128），语义模型下载同样使用该线程数；下载中可取消，并可一键打开下载目录
- **备份与恢复**：全量备份导入导出，可选是否包含 API Key
- **欢迎面板**：统计概览（笔记 / 分类 / 回收站）与最近更新列表
- **系统集成**：统一设置面板（可搜索）、开机自启动、托盘图标、关闭窗口行为

## 配置

### 笔记搜索

- 侧边栏搜索框内的 `.*` 图标切换正则模式：开启后按正则表达式匹配标题与正文，关闭时 `*`、`(` 等字符按字面量处理。正则不合法时本次搜索返回零结果并给出提示。

### 语义搜索

- 默认关闭。语义搜索的总开关只在「设置 → 语义搜索」里，打开后在同一分区选择模型并下载，等待索引建立。
- 可选模型（均为 int8 量化版，下载体积以面板显示为准）：
  - `BGE Small 中文`（推荐，512 维，约 24 MB）：体积小、速度快，适合大多数中文笔记。
  - `BGE Base 中文`（768 维，约 103 MB）：语义区分更细、检索更准，索引与查询更慢。
  - `Multilingual MiniLM`（384 维，约 135 MB）：支持中英等 50 多种语言，适合混写或外文笔记。
- 支持从本地导入自定义 ONNX 句向量模型：在「设置 → 语义搜索 → 导入模型」选择目录，目录内需有 `model.onnx` 与 `tokenizer.json`（单文件模型，暂不支持外部权重文件），并填写向量维度、最大 token 数、池化方式（CLS / Mean）与可选的相似度阈值。
- 导入只读取源目录，不移动或删除原文件；文件先复制到临时目录，再用填写好的元数据真实加载并嵌入一次做自检，维度不符、输出无效或文件不是有效模型都会直接报错，且不留下半成品。模型按两个文件的 SHA-256 内容哈希命名（`models/custom-<16 位哈希>/`），重复导入同一模型会提示已存在；清单记录文件大小与哈希，文件被替换后状态显示「文件缺失」，需重新导入。
- 自定义模型的维度、池化方式与阈值来自导入时填写的值，填错会在自检阶段失败；ONNX 由本地推理库解析，请只导入可信来源的模型文件。自定义模型不支持在线下载，删除后需要重新导入。
- 切换模型后，后台会按新模型重建全部笔记的向量索引；旧模型的向量不会被读取。
- 语义搜索目前为测试功能：结果是模型按相似度排序的近似匹配，不同模型的语言支持与区分能力不同，未必精准命中；功能与性能仍在调整，建议保留普通文本搜索作为主要方式。
- 「自动建立索引」默认开启：模型下载完成后自动建立索引，之后新增或修改的笔记自动增量更新。关闭后只在手动点「重建索引」时建立/更新。
- 模型目录：`<数据目录>/models/<模型 id>/`，需要 `model.onnx`、`tokenizer.json`；`manifest.json` 由下载器或首次成功加载自动生成。离线环境可手动放入前两个文件（且大小达标），再在面板里重建索引。
- 数据目录与数据库相同：优先程序所在目录下的 `data`（Windows 下如 `<安装目录>\data\models\bge-small-zh-v1.5-int8\`，整个目录可便携搬走）；安装目录不可写时退回 `%APPDATA%\com.smartist.fastnote\models\<模型 id>\`。旧版本放在应用数据目录的模型会在启动时自动迁移。面板里可复制当前模型目录，或直接在文件管理器中打开。
- 下载前会检查两个模型文件是否已完整存在，已下载的模型不会重复下载；下载源优先 `hf-mirror.com`，失败回退 `huggingface.co`；中断后支持断点续传。下载走统一的下载模块，按「设置 → 工具箱」里的线程数（默认 32，最高 128）分段并发；服务器不支持分段或文件较小时自动退回单流。同一时间只允许一个下载任务，设置面板会显示进度、已下载体积与网速；成功或失败都有提示。
- 笔记向量存放在本地 SQLite 的 `note_chunks` 表，删除模型或重建索引不会影响笔记内容。
- 开启后，AI 助手会多出 `searchNotesSemantic` 工具；检索范围仍受「AI 访问权限」约束。

### 工具箱

- **下载线程**：`app.config.general.downloadThreads`，默认 32，可填 1–128；改完在下一次下载任务生效，语义模型下载与工具箱下载共用。
- **链接下载**：粘贴 http / https 链接即可下载，默认保存到软件安装目录下的 `download` 文件夹（安装目录不可写时退回应用数据目录下的 `download`）。
- 文件名取链接路径的最后一段并做非法字符清理；重名时自动追加 ` (1)`、` (2)`，不覆盖已有文件。下载过程显示进度、体积、网速与实际分段数（服务器不支持 Range 时提示已退回单线程），可随时取消，取消后清理临时文件；完成后提示保存路径并可在文件管理器中定位，也可直接打开下载目录。

## 构建

```bash
pnpm install          # 安装依赖
pnpm dev              # 开发模式（桌面端）
pnpm build            # 打包桌面应用
```

首次构建 Rust 端时，`ort` 会从 `cdn.pyke.io` 下载 ONNX Runtime 预编译库并缓存；离线构建需提前准备缓存。语义模型不随安装包分发，运行时按需下载。

## 技术栈

- 前端：React 19 + TypeScript + Vite + Tailwind CSS
- 桌面端：Tauri 2 (Rust 后端)
- 编辑器：自研 Markdown 编辑器（src/markdown-editor，自研解析器 + 三种视图 + 全量可配置）
- 数据库：SQLite（笔记数据 + AI 设置加密存储）
