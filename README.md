# FastNote

一款本地优先的桌面 Markdown 笔记应用，基于 Tauri 2 + React + TypeScript 构建。

## 功能

- **AI 笔记助手**：内置查找、写入、按行编辑、删除、移动、回收站等笔记与分组工具，支持深度思考、工具轨迹、上下文压缩与记忆提示词；兼容 OpenAI / Claude / Gemini 三种协议，API Key 加密存储，可按笔记与分组设置 AI 访问权限；编辑区选中文本可一键润色、翻译、总结或加入对话
- **本地语义搜索**：内置多款中英文句向量模型，也可导入自定义 ONNX 模型，在本机建立向量索引，换述、同义也能命中；建好索引后完全离线，未启用时不影响普通文本搜索
- **Markdown 编辑器**：源码 / 分栏 / 预览三种视图，代码高亮、行号、任务列表、公式（KaTeX）、流程图（Mermaid）、查找替换、大纲
- **历史版本**：按间隔自动快照，也可手动「存版本」；支持只读预览、与当前内容逐行对比、回滚、固定与清理策略（自动版本保留最近 N 份，最早一版始终保留）
- **笔记管理**：分组、标签、置顶/收藏、回收站、拖拽归类、排序与全文搜索（支持正则）
- **外部文件**：拖入或打开电脑上的文本文件直接编辑，修改实时写回原文件，也可另存为笔记
- **导出**：单篇导出为文件；分组导出为 ZIP 压缩包或电子书（TXT / HTML / EPUB）
- **备份与恢复**：JSON / SQLite 整库备份，支持 WebDAV 云同步与定时自动备份，备份可选是否包含 API Key 与 WebDAV 配置
- **笔记加密**：笔记或分组可设独立密码，数据库里的正文、标签与历史版本以密文保存（笔记名保持明文）；加密后立即锁定，单击笔记或展开分组时输入密码临时解锁（本次运行 / 仅一次），右键可永久解密，条目密码连错 3 次后可用根密码解锁。首次启动引导设置根密码，遗忘后没有任何找回手段；加密内容不参与导出、保存、备份、删除、AI 与语义搜索，删除前须先永久解密（回收站内同样可以解密）
- **工具箱**：链接下载器（多线程分片、断点合并、随时取消、自定义文件名）与浏览器指纹查看
- **桌面集成**：托盘图标、开机自启动、关闭到托盘、单实例运行
- **自动更新**：应用内检查更新（启动时静默检查，运行期间按设置间隔自动检查，间隔在「关于」里可调，默认 10 分钟；CNB / GitHub 双线路，下载失败自动换线重试），弹窗内可查看下一版本说明、跳过此版本、稍后再说或直接安装，下载中显示进度、速度与剩余时间；更新完成后展示本次更新内容
- **多语言**：简体中文 / English，可跟随系统语言

## 开发

```bash
pnpm install
pnpm dev      # 桌面端开发模式
pnpm build    # 打包桌面应用
pnpm test     # 单元测试（解析器 / 模糊匹配 / 搜索）
```

## 技术栈

- 前端：React 19 + TypeScript + Vite + Tailwind CSS
- 桌面端：Tauri 2（Rust）
- 编辑器：自研 Markdown 编辑器（自研解析器 + 三种视图）
- 数据：本地 SQLite，AI Key 加密存储
