# 发布验收清单

CI 只证明「类型对、单测过、能打包」。界面行为、升级路径、真机交互它碰不到，
所以每次发版前手动走一遍。**目标 10 分钟内做完**，任何一条不过就别发。

> 用法：复制到 issue / 发版说明里逐条打勾。真机 = 装出来的 NSIS 包，不是 `tauri dev`。

## 0. 打包前

- [ ] `package.json` 版本已改，且 `pnpm version:sync` 跑过（提交里含 `Cargo.toml` / `tauri.conf.json` 两处变更）
- [ ] `cargo test --release --lib` 全绿（140+）
- [ ] `pnpm test` 全绿（43）
- [ ] CI 的 Release 流程走完，安装包与 `latest.json` 都在

## 1. 启动与界面（真机）

- [ ] 冷启动无白屏/黑屏，splash 收起后是主界面
- [ ] 数据目录下出现 `log/fastnote-<今天>.log`，首行是 `===== FastNote v<版本> 启动 =====`
- [ ] 新建笔记 → 输入 → 500ms 内自动保存 → 重启后内容还在
- [ ] 删除到回收站 → 还原 → 永久删除，三步都对
- [ ] 侧栏分组拖拽排序、置顶、标签筛选各点一次
- [ ] 切一次深色/浅色主题，重启后保持

## 2. 编辑器

- [ ] 粘贴图片：落在 `attachments/`，预览按比例占位
- [ ] Ctrl+F / Ctrl+G / Ctrl+H 正常；Ctrl+P 不再弹打印
- [ ] 大笔记（>1 万字）滚动不卡、光标位置正确
- [ ] 从 Word / 网页粘贴富文本，格式没有崩

## 3. 备份与恢复（**最该认真做的一项**）

- [ ] 备份设置 → 导出 JSON → 文件大小合理（开「只备份笔记」后应明显变小）
- [ ] 导出的 JSON 能被「选择文件」预检，勾选项与库内数量对得上
- [ ] 恢复后抽查 3 篇笔记正文、图片、标签、置顶状态
- [ ] SQLite 快照导出 → 恢复（合并语义），本地独有内容没被删
- [ ] `.fnbak` 加密备份：导出 → 输错口令被拒 → 正确口令恢复
- [ ] WebDAV：测试连接 → 手动备份（`.gz`）→ 云端列表能看到 → 取回 → 勾选恢复
- [ ] 云端「最多保留 N 份」生效：连传 3 份，旧文件被删且**手动备份没被动**
- [ ] 恢复前若是本地更新，弹「同步冲突」，三条出口各点一次

## 4. 加密

- [ ] 设置根密码 → 加密一篇笔记 → 锁定 → 解锁
- [ ] 加密笔记里插图：弹出「图片明文存放」提示（首次）
- [ ] 加密笔记不进 AI / 语义搜索 / 不含在「只备份笔记」的备份可读范围
- [ ] 备份（含根密码材料）→ 换机路径：恢复到新库后能用原根密码解锁

## 5. 插件

- [ ] 安装一个 zip 插件 → 出现在列表 → 打开窗口 → 数据写入 `plugin-data/`
- [ ] 卸载时询问「删表/保留」，选择生效
- [ ] 插件注册的快捷键与宿主冲突时被拒绝并提示

## 6. AI

- [ ] 对话能流式返回，中途「停止」真的停（后端 token 不再烧）
- [ ] 工具调用能读笔记、改笔记；权限为「只读」时写入被拒
- [ ] 切换模型后下一轮生效；重启后仍是所选模型
- [ ] 断网时提示友好，不是一串英文

## 7. 升级路径（旧版 → 新版）

- [ ] 用**上一个发布版**建库、写几篇笔记，再装新版启动
- [ ] 数据目录出现 `pre-migration-<旧>-to-<新>-<时间>.db`，大小与原库接近
- [ ] 迁移后笔记、加密笔记都能打开
- [ ] 升级后 `log/` 里没有 ERROR 级记录

## 8. 故障演练（每个大版本抽一个做）

- [ ] 把 `fastnote.db` 前 1KB 改成乱码 → 启动：应用能开、提示「数据库损坏已重建」、原文件被改名 `.corrupt-*`
- [ ] 断网连点 3 次 WebDAV 备份 → 日志里有清晰错误，界面不卡死
- [ ] 设置 → 关于 → 导出诊断包：zip 里有 `diagnostics.txt` 与最近日志，**不含数据库**

## 9. 安装体验

- [ ] 全新安装：能装、能启动、无残留旧版
- [ ] 卸载：程序目录清掉，`data/` 与 `log/` 是否按预期保留（至少在发版说明里写清）
- [ ] SmartScreen 提示是否已知（未签名时必然出现，发版说明里提前说明）
